## 8. 模擬実装の範囲と未実装事項

- データ：架空の分析4件と、画面で作成した分析。ページ内メモリだけで保持し、ブラウザの再読み込みと「架空データを初期状態に戻す」で元に戻る。
- 3画面は同じデータを扱う。一覧で開いた分析、新規作成した分析が、そのまま分析・編集に表示される。
- 生成：模擬。候補名はどの分析でも同じ汎用の文言で、実際の生成内容ではない。件数は見やすさのため既定値より少ない（一次3件、二次・三次2件、追加2件）。結果は検証用の「生成の模擬結果」で選ぶ。
- 保存：すべてページ内の模擬保存。本番API・DBには接続しない。
- 出力：通知のみで、ファイルは出力しない。
- 生成中の制限：画面の移動と要因の削除を止める。削除は、ボタンの無効化に加えて、削除確認を開く処理と削除を確定する処理でも生成中かを確認する。生成結果を反映する直前に親要因の存在を確認し、親がなければ子要因を作らず「親なし」と表示する。いずれも模擬上の制限で、本番の扱いは未決定。
- 「架空データを初期状態に戻す」は比較用の操作で、通常の要因削除とは別扱い。実行中の模擬生成は破棄される。
- 未実装：再読み込み後の保存、ファイル出力、ダイアログのフォーカス閉じ込めとEscで閉じる操作、生成中の操作の本番相当の扱い。
- 画面上部の採用元表示と、枠外の検証用の操作は、本番画面には含めない。

### 実施した確認

- 統合案 第2版の最終ファイルに対して新たに実行した。第1版の138項目とA/B比較版（第3版）の252項目の結果は流用していない。
- 確認した内容：
  - 画面間の遷移（一覧→既存分析、一覧→新規作成→作成して編集、新規作成→キャンセル→一覧、編集→一覧へ）

  - タイトルと更新日時の一致（編集で改名→一覧、一覧で改名→編集）
  - 評価、詳細編集、手動追加、要因の削除件数、作業・ツリー・一覧表への到達
  - 未保存保護（要因の切替、一覧へ戻る、新規作成への移動、新規作成のキャンセル、空タイトル、変更なしでは確認なし）
  - 生成結果の6状態（一部失敗では作成と処理失敗を併記）、生成中の移動の抑止、絞り込みと一括生成対象、生成前の保存条件
  - 重要なボタンの欠け・重なり（中心点の最前面が自分自身であること。通知表示中を含む）
  - I-01：正常生成中に削除ボタンが無効で、ボタンを経由しない削除確認・削除確定も止まること。正常・一部失敗・全候補除外・通信失敗の終了後に削除できる状態へ戻り、実際に削除できること。親のない子要因がないこと。生成ログの作成件数と、各親の下に作られた子要因の数が一致すること。反映直前に親が消えた場合（処理を直接呼んで再現）に子要因を作らないこと。生成中の「架空データを初期状態に戻す」でエラーや親のない子要因が出ないこと
  - 再現確認：修正前の第1版と修正後の第2版に同じ手順（生成中に選択中の親を削除）を実行し、結果を比較（検証記録タブと `evidence/repro.json`）
