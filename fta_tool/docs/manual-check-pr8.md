### 切り戻しの方法（計画書 第9節）

- 基準ブランチへ統合した後に戻す：統合のマージコミットを `git revert -m 1 <マージコミット>` で戻す（履歴を残す。強制 push はしない）。
- 利用環境だけ戻す：統合前の SHA `8a50db1` を取り出して再起動する。DB のスキーマ・API は変えていないので、改修後に作ったデータはそのまま旧画面で使える。ブラウザに保存した値（`fta:edit:v1:*`・`fta:genlog:v1:*`）は旧画面では使われない。
- 戻した後は、3画面で強制の再読み込み（Ctrl+F5）を行う（静的ファイルのキャッシュ制御は旧版にはないため、古い CSS・JS が残りうる）。

## 5. 利用者に残る最小限の確認（Windows、所要 15〜20 分の見込み）

自動試験と既存の記録で確かめられないのは、(a) 統合した版を利用者の普段の起動方法で動かすこと、(b) 実データの DB で開けること、(c) 代表的な流れの一通りの実操作の感触、の3点。Full の再実行は求めない（コードが `b118038` と同じため。再実行するかは利用者の判断）。

**普段の DB は使わない**（写しを使う）。AI は mock（`AI_PROVIDER=mock`）。

手順1：受入対象の SHA の取り出しと確認（PowerShell）

```powershell
$sha = "<PR-8 をマージした後の feature/ui-redesign の先頭の SHA（40桁）>"
git fetch origin feature/ui-redesign
git worktree add --detach "C:\fta-check\src-pr8" $sha
Set-Location "C:\fta-check\src-pr8"
git rev-parse HEAD        # $sha と一致すること
git status --short        # 何も出ないこと
git diff --name-only b118038a5fa37eaa28fceb20e54102c7a0906343 HEAD -- . ':(exclude)fta_tool/docs' ':(exclude)fta_tool/README.md'   # 何も出ないこと
```

手順2：新しい DB での起動（普段と同じ Python・venv を使う。新しいフォルダを作業フォルダにする）

```powershell
New-Item -ItemType Directory -Path "C:\fta-check\pr8-new" | Out-Null
Set-Location "C:\fta-check\pr8-new"
$env:AI_PROVIDER = "mock"
python -m uvicorn app.main:app --app-dir "C:\fta-check\src-pr8\fta_tool" --port 8001
```

ブラウザ（普段使うもの。Edge または Chrome）で `http://localhost:8001/` を開き、一覧・新規作成・（作成後の）編集の3画面でそれぞれ1回 Ctrl+F5 を押す。

手順3：代表の流れ（シナリオ 1・3・4・9 を1回ずつ）

1. 一覧（0件）→「＋ 新規分析を作成」→ サンプルを転記 → 分析タイトルを入力（Microsoft IME で日本語）→「作成して編集へ」→ ①が開く。
2. ②「一次要因を生成」→ 生成ログに親ごとの結果、通知が作業エリアの下に出る。
3. 一次要因を1件 Yes、1件 No にし、③「Yesの一次要因から二次要因を生成」→ 対象の親名と件数が操作バーに出て、Yes の親だけに二次要因ができる。
4. 別の一次要因のインスペクタで「AIで追加生成」、さらに別の親で「手動追加」→ 追加先が正しく、AI／手動のタグが付く。
5. ⑤から JSON か Markdown を1つダウンロードして開き、分析の内容が入っていることを見る。
6. 見え方：通知が操作を覆わない、保存・取消が見える、文字の重なり・欠けがない（ウィンドウは普段の大きさ・拡大で）。

手順4（任意）：実データの DB の写しで開く

普段の `fta_tool.db` を新しいフォルダに**コピー**し、そのフォルダで手順2と同じように起動して、一覧と、要因の多い分析の編集画面を開く（開くだけ。写しなので変更しても普段の DB には影響しない）。不整合のある要因があれば、編集画面の構造ナビの末尾「親子関係に不整合がある要因」に出る（S-11・S-12 の判断の材料になる。出た場合は、その分析を一覧から削除しないで報告する）。

後片付け：サーバーを Ctrl+C で止め、`git worktree remove "C:\fta-check\src-pr8"`、`C:\fta-check\pr8-new` と DB の写しのフォルダを削除する。
